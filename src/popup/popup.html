Quick start

  1. Open a supported HTTPS camera website.
  2. Enable Veyl for the current origin and reload the page.
  3. Move away and capture a clean background.
  4. Press Ctrl/⌘ + Shift + X or use a camera gesture.

◉ Camera frames, masks, hand landmarks, and background plates stay on this device. Veyl does not request microphone access for gestures.
